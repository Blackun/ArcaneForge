# 📖 Arcane Forge: 게임 플레이 & 공략 가이드

본 문서는 **《Arcane Forge: Merge & Restore (아케인 포지: 마법 공방 복구기)》** 의 전체 생산 체인, 이종 교차 연성 레시피, 보스 몬스터 약점 공략 및 편의 기능을 정리한 공식 가이드입니다.

---

## 1. 기본 조작 및 핵심 시스템

| 조작 / 기능 | 설명 |
| :--- | :--- |
| **생성기 탭 (클릭)** | `드워프의 모루`, `연금술 증류기`, `고대 룬 비석` 등 생성기(⚡ 배지 표시)를 클릭하면 에너지를 소모해 인접한 빈 칸에 1~2레벨 재료를 생성합니다. |
| **동일 아이템 머지** | 같은 종류·같은 레벨의 아이템 2개를 드래그해 겹치면 상위 레벨(+1 Lv) 아이템으로 합성됩니다. |
| **크리티컬 머지 (8%)** | 머지 성공 시 8% 확률로 **+2 레벨 상위 아이템**으로 단숨에 도약합니다! |
| **럭키 드롭 (15%)** | 생성기에서 아이템 소환 시 15% 확률로 인접한 빈 칸에 보너스 재료가 하나 더 생성됩니다. |
| **보관함 (창고)** | 당장 쓰지 않는 고레벨 재료나 생성기를 하단 보관함(기본 5칸, 골드로 최대 10칸 확장)으로 드래그해 보드 공간을 확보할 수 있습니다. |

## 3. 4대 이종 교차 연성 (Cross-Crafting) 레시피

서로 다른 체인의 아이템을 보드 위에서 직접 드래그해 포개면 **보라색 룬 마법진**이 활성화되며 하이브리드 아티팩트가 연성됩니다.

| 완성 아티팩트 | 재료 A | 재료 B | 주요 활용처 |
| :--- | :--- | :--- | :--- |
| **🗡️ 홍련의 마검** (`hybrid_flameblade`) | 기사의 장검 (`weapon_4`) | 화염의 영약 (`potion_5`) | 제3구역 마법 부여 제단 복구 & **타락한 고대 룬 골렘 특효 약점** |
| **⚡ 뇌전의 룬검** (`hybrid_runeblade`) | 미스릴 대검 (`weapon_5`) | 각인된 룬석 (`arcane_2`) | 제4구역 고대 비전 서고 복구 & 고위력 보스 타격 |
| **📗 생명의 금서** (`hybrid_tome_of_life`) | 고대 마도서 (`arcane_4`) | 불사조의 비약 (`potion_6`) | 제4구역 최종 복구 & **심연의 금서 망령 특효 약점** |
| **🌟 에테르 코어** (`hybrid_aether_core`) | 정령의 보주 (`arcane_5`) | 현자의 돌 (`potion_7`) | 제5구역 천공의 에테르 성소 최종 복구 & **에테르 드래곤 일격필살** |

| 출현 구역 | 보스 몬스터 | 체력 (HP) | 약점 카테고리 (1.5배) | 일격필살 특효 아이템 | 토벌 보상 |
| :--- | :--- | :---: | :---: | :--- | :--- |
| **화염의 대장간** | 🔥 **잿더미 용암 슬라임** | 50 | 무기 (`weapon`) | `강철 주괴` / `수습생의 단검` | `🪙 60G` + `⚡ 15` + `🎁 보급상자 Lv.1` |

## 5. 테스트용 치트 툴바 안내

화면 우측 상단 치트 툴바에서 모든 콘텐츠를 기다림 없이 즉시 체험할 수 있습니다:
- **`⚡ +100 에너지`**: 에너지를 즉시 100 충전합니다.
- **`🪙 +500 골드`**: 창고 슬롯 확장 등에 필요한 골드를 500 추가합니다.
- **`🎁 보급상자`**: 보드 빈 칸에 희귀 보급상자를 즉시 소환합니다.
- **`🗡️ 전설 무기고`**: 현재 상대 중인 보스 몬스터의 **특효 약점 무기**와 **홍련의 마검**을 보드에 즉시 소환합니다.
- **`✨ 퀘스트 재료`**: 현재 진행 중인 복구 퀘스트에 필요한 납품 아이템을 즉시 소환합니다.
- **`🔄 초기화`**: 저장 데이터를 초기화하고 프롤로그부터 새로 시작합니다.
